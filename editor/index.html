文字で書いて、図にする

Law図ローズ

図を文字で書くエディタです。「代理人は本人の下」「本人から代理人へ矢印」のように図形どうしの関係を書くと、図になります。座標や大きさを決めなくても、ラベルの長さに合わせて間を空けます。

使い方

  • 左に文字を書くと、右の図が変わります。
  • 図形をドラッグして、ほかの図形の上下左右に寄せて置けます。置き方は文字に書き戻されます。
  • Shift を押しながら選ぶと、いくつも選べます。選んだ図形の段や列を揃えたり、線でつないだりできます。
  • 書いたものは .zu(文字)と SVG(図)で保存できます。SVG はほかの文書や Web ページにそのまま貼れます。

書き方の早見

text a "本人"
図形を置く。text は枠のない文字、ほかに parallelogram(平行四辺形)と cube(立方体)
below a
a の下に置く。above、left of、right of も。何も書かなければ直前の図形の右
align row b c
b と c を同じ高さに揃える。column なら左右の位置を揃える
a --- b
線を引く。-.- は点線、=== は二重線
a ---> b "ラベル"
端の印とラベル。> は矢印、>> は塗った矢印、o は丸。両端に付けてもよい

書いたものの行方

書いた文字はこのブラウザの中にだけ保存され、どこにも送られません。別の端末やブラウザで続けるときは「.zu を保存」で書き出し、「開く」で読み込んでください。

名前

Law図 は「ローズ」と読みます。法律の関係図を描きたくて作り始めましたが、図形の名前は分野に寄せていないので、ほかの図にも使えます。書くための言語の名前は zu、ファイルの拡張子は .zu です。
