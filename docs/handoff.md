# 引き継ぎ(2026-11-07)

論証ドリル(`../shiho`)の作業中に始め、独立させた。ここまでの検討と、決めていないことをまとめる。

## 始めた理由

司法試験の学習で、代理(本人・代理人・相手方)のような法律関係を図で表したかった。まず Mermaid を試したが、図形を思う位置に置けず、線の描き分けにも制約があったので、自分で記述言語を作ることにした。

## Mermaid で試したこと(Mermaid 11.4.1、Chrome で描画して確認)

代理の三者関係(本人と代理人の間に代理権の授与、代理人と相手方の間に意思表示の合致、本人と相手方の間に契約成立・効果帰属)を描いた。

flowchart:

- 配置は自動で、教科書のような三角形(本人と相手方が上、代理人が下)にできない。左から右に一列に並ぶ
- 線の太さ(`linkStyle`)と双方向の矢印(`<-->`)は効く
- `===`(太い線)にも矢じりが付いた

block-beta:

- `columns` と `space` で格子に置けるので、三角形にできる
- 枠を詰めて並べると枠が小さくなり、線のラベルが重なって読めない。空きのマスで間を空ける必要があった
- `linkStyle` は構文エラーになり、図全体が描けなくなる
- `<-- "…" -->` は通るが、矢じりは片側にしか付かない
- `---`(矢じりなし)も矢印で描かれる

結論: 配置の自由と線の描き分けを両立できなかった。

## 方針

- Mermaid の書き味(1行に1文、`%%` のコメント、引用符のラベル)を参考にしつつ、置き方を自由にすることを優先する
- 処理を構文、配置、描画の3段に分け、互いに独立させる。描画先を SVG 以外に変えるときは最後の段だけを替えればよいようにする
- 言語の語は法律に限らない言い回しにする(参加者は `text`、土地は `parallelogram`、動産は `cube`)

## v0 でできること

- 図形: `text`(枠なしの文字)、`parallelogram`(平行四辺形)、`cube`(立方体、ラベルは下)
- 置き方: `right of a by 40` などの相対配置(`of` は省略可、間は外枠どうしの距離で既定 40)、何も書かなければ直前の図形の右、`at x y`(座標)。位置は図形の本体(cube ならラベルを除いた立方体)の中心で決める
- 揃え: `align row b land`(同じ段)、`align column a b`(同じ列)。数を書かずに揃えられる(2026-11-07 追加)
- 後に書いた図形も参照でき、存在しない参照、循環、名前の重複は誤りになる
- `size`、複数行のラベル(`\n`)、コメント

詳しくは SPEC.md。

## 決めていないこと、次にやりたいこと

検討中の資料:

  - 太さや破線で意味を分ける(意思表示と契約の効果を見分けるなど)

- 文字幅は全角1字、それ以外0.6字で見積もっている。書体によっては長い文字列がずれる

- 論証ドリルに組み込むか(論証や知識に図を添える、など)。組み込むなら、論証ドリルのデータは利用者ごとに閉じている点(第三者の著作物を含み得るため共有しない)に合わせる
- 視覚的なエディタ(design/editor.md)。今は SVG を出してブラウザや VS Code で開く
