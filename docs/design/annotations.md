# 検討: 図形に添える注釈(2026-11-08)

書き方 A(`a says`、`a note`)、注記は (a) 小さな字だけ、置き場所は下の表の順と2語の書き方、線には後で、と決めて入れた(2026-11-08、仕様は SPEC.md の「注釈」)。注記を字だけにしたのは、鉛筆で描ける形に限るため([principles.md](principles.md))。以下は検討の記録。

図形に紐づけて短い文を添えたい。二通りある。

- **発言**: A が何かを言っている(「売ります」「追認します」)。吹き出しで描く
- **注記**: A についての事実や状態(「無資力」「登記あり」「悪意」)。図形のすぐ近くに小さく書く

今は `text` を別に置くしかない。それだと次の点で困る。

- 意味が伝わらない: どの図形の注釈なのかが書き方に表れない
- 置き方が不自由: 置き方は上下左右だけなので、斜め(右上など)に置けない
- 動きについてこない: 図形を動かしても、注釈は一緒に動かない
- 間が空く: 既定の間(40)で離れてしまう

## 決めること

1. 書き方
2. 置き場所の決め方
3. 見た目(特に注記)
4. 線にも付けるか

## 1. 書き方

| 案 | 書き方 | 良い点 | 気になる点 |
| --- | --- | --- | --- |
| A. 図形の名前を先に | `a says "売ります"`<br>`a note "無資力"` | 「A が言う」の語順で読める。線の文(`a ---> b`)と同じく、名前から始まる | `text says "x"` は今も「says という名前の text」と読める。図形の種類と同じ名前の図形には付けられない(図形の文を優先する) |
| B. 語を先に | `says a "売ります"`<br>`note a "無資力"` | `align`、`caption` と同じ並びで、読み違いがない | 「言う a」の語順になる |
| C. 図形の文に足す | `text a "本人(A)" says "売ります" note "無資力"` | 一行で済む | 図形の文が長くなる。いくつも付けにくい。エディタで書き換える範囲も広がる |

推すのは A。

- 1つの図形にいくつ付けてもよい(`a note "無資力"` と `a note "登記"` の2行)
- ラベルと同じく `\n` で改行できる
- 置き場所を語で添えられる: `a says "売ります" above right`。添えなければ自動で決める(2.)

## 2. 置き場所

既定は自動にする。図形のまわりの候補を順に試し、ほかのものに重ならない最初の場所に置く。避けるのは図形、線、線のラベル、ほかの注釈。

| 種類 | 試す順 | 図形との間 |
| --- | --- | --- |
| 発言(吹き出し) | 右上、左上、上、右、左、右下、左下、下 | 吹き出しの尾の分(12) |
| 注記 | 下、右、左、上、右下、左下、右上、左上 | 小さく(4) |

- 吹き出しは、漫画と同じく頭の上(斜め上)から試す。注記は名札のように下から試す
- 置き場所を書けば、その場所に置く。重なっても動かさない。斜めは `above right` のように2語で書く(置き方の語 `above`、`below`、`left`、`right` を使う)
- 同じ図形の注記どうしは、続けて並べる(「無資力」の下に「登記」)
- 注釈は図形の位置を変えない(線と同じ)。図の範囲には含める
- 置く順は、線とそのラベルを置いた後。線のラベルは注釈を避けないが、注釈は線のラベルを避ける

## 3. 見た目

- **吹き出し**: 角の丸い白い枠に、尾(三角)を付けて図形の本体の縁へ向ける。字の大きさは図の中と同じ
- **注記**: 次の3案。見本は Artifact「注釈の見た目」で示す
  - (a) 小さな字だけ(12)
  - (b) 小さな字を、薄い灰色の角丸の札に入れる
  - (c) 小さな字を、細い枠で囲む
  - 推したのは (b) だったが、(a) に決めた。色の付いた下地は鉛筆で描けないため

## 4. 線に付けるか

注記は、名前を付けた線(`as f`)にも付けたくなる(「時価100万円」「登記済」など)。ただ、今はラベルで足りることが多いので、まず図形だけにする。線に付けるときは、線の中点のまわりに置く。

## エディタ

- 図形のパネルに「注釈」の欄を足す。「吹き出しを足す」「注記を足す」で行を足し、文、種類、置き場所(自動、上、右上、…)、消すボタンを並べる
- 図形の名前を変えたら、注釈の名前も書き換える。図形を消したら、その注釈も消す

## 決めたこと

1. 書き方は A(`a says "…"`、`a note "…"`)
2. 注記は (a) 小さな字だけ
3. 置き場所は上の表の順。語で決めるときは `above right` の2語
4. 線に付けるのは後回し

## 入れてから分かったこと

- 置き場所を書いた注釈は、ほかのものに重なっても動かさない。置き方を書かない図形が直前の図形の右に来て、注釈と重なることがある(書いた側の責任とする)
- 吹き出しの斜め(右上など)は、図形の中心から外へ伸ばす。外枠の角の外に置くと、図形から離れて見えた
