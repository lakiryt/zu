# 検討: 視覚的なエディタ(2026-11-07)

ブラウザで図をクリック・ドラッグして配置を変え、その結果を .zu として書き出すエディタ。`editor/` にある。Vite で束ね、Vercel に静的サイトとして置く(`vercel.json`)。

## 方針

- **正本は .zu の文字**。画面は文字・図・パネルの3つ。図やパネルの操作は文字の該当する文だけを書き換え、構文→配置→描画をやり直して図を描き直す。コメント、空行、ほかの行には触れない
- **ドラッグは既定でスナップさせ、数を書かせない**。自由にドラッグできると数(`at 123 456`、`by 87`)だらけの .zu ばかりになり、「数に頼らない」方針([placement.md](placement.md))に反する
- **数を直接指定するのは高度な操作にする**。パネルの「高度な設定」(閉じてある)と Alt+ドラッグだけで数を書く。数を書いた図形には印(右上の橙の点)を付け、数が増えていないか気づけるようにする
- 保存は .zu と SVG の書き出し、.zu の読み込み(端末内のファイル)だけ。サーバーには何も送らない。論証ドリルのデータを利用者ごとに閉じる方針と合う。作業中の文字はブラウザの localStorage に覚える(その端末のそのブラウザだけ)

## 最初の版でできること

| 操作 | 書き換え |
| --- | --- |
| 図形をドラッグして、ほかの図形の上下左右(既定の間の位置)に寄せる | `below of c` などの置き方にする。間は書かない |
| 寄せる先のない所で放す | 何もしない(元に戻り、寄せ方の案内を出す) |
| Alt+ドラッグ(関係で置いている図形) | その線の上だけを動き、`by` を書く |
| Alt+ドラッグ(`at` か置き方なしの図形) | 自由に動き、`at x y` を書く |
| Shift+クリックで複数選び「段を揃える」「列を揃える」 | `align row …` / `align column …` を足す。同じ向きの揃えに既に入っている図形があれば、その揃えに加える |
| パネルで名前を変える | 名前と、それを参照する置き方・揃えをまとめて書き換える |
| パネルでラベル・形を変える、置き方や揃えを「外す」 | その文だけ |
| 高度な設定で間・座標・大きさを入れる | `by`、`at`、`size` |
| 図形を足す(ツールバー) | `図形1` のような名前で末尾に足す。置き方なし(直前の図形の右) |
| 図形を消す(Delete キーでも) | 文を消す。揃えから外し、その図形を基準にしていた図形は、消した図形の置き方を引き継ぐ |
| 元に戻す・やり直す(Ctrl+Z / Ctrl+Y) | 文字の履歴。文字の欄で続けて打った分は一つにまとめる |
| 文字の欄でカーソルを動かす | その行の図形を選ぶ |

書き換えた結果が誤りになる操作(循環するなど)は取り消し、理由を出す。文字の欄に誤りがあるあいだは図を薄くし、図での操作を止める。

## 暫定の判断(使ってみて詰める)

- ドラッグ中は、動かす図形と、それについてくる図形(置き方をたどってその図形に行き着くもの)を一緒に動かして見せる。ついてくる図形は吸着先の候補から外す(循環を防ぐ)
- 吸着先は、ほかの図形の上下左右に既定の間で置いた位置だけ。半径 56(図の単位)以内でいちばん近いもの。ほかの図形と重なる位置にも吸着する
- 吸着して書いた置き方は `below of c` の形(`of` を付ける)。文を書き換えると、`of` の有無や数の間の「,」はこの形にそろう
- ドラッグでは `align` を足さない。揃えは選んでボタンで足す。ドラッグ中に段や列が揃いそうなら案内する、という案もある
- 図形を足すときは置き方なし(直前の図形の右)。選んでいる図形の下に足す、などもあり得る
- 図形を消すとき、基準にしていた図形には消した図形の置き方を引き継がせる。消した図形の位置に残したいならこれで近くなるが、間はずれる
- 図が広いときは枠に収まるよう縮めて表示する。拡大・縮小の操作はまだない

## 作りの要点

- 構文の段は、文の始まり(`at`)と終わり(`end`、行末のコメントを含まない)を持つ。`src/syntax/print.ts` が文を文字に戻す。エディタは文の範囲を `print` の結果で置き換える(`editor/edit.ts`)
- 配置の段の `Scene` は、各図形の本体の中心(`anchor`)と、書いた座標の原点が図のどこに来たか(`origin`)を持つ。吸着の計算(`editor/snap.ts`)は `anchor` を、Alt+ドラッグの `at` は `origin` を使う
- 配置の段は全体を余白の内側へずらすが、ドラッグ中は描き直さない(放したときに描き直す)ので、ずれは問題にならない
- `edit.ts` と `snap.ts` は DOM を使わない。`tests/editor.test.ts` で試す。画面の操作は、Chrome をヘッドレスで起動し CDP でドラッグして確かめた(リポジトリには入れていない)
